## 为什么需要它

规范 §6.1 规定探针取"包含该坐标的顶层单元",并对**边界歧义**给了两级裁决
(单元中心欧氏距离最近 → element id 最小)。它没有说的是:**如果坐标根本
不落在任何顶层单元内,该怎么办。**

这不是纸上谈兵的边界情形,它由三个已知事实共同构成:

1. 预注册坐标是绝对值 `(1.0/2.0/3.0, 2.0) mm` 加"顶层单元中心高度",而
   z 的具体值取决于网格。当前 M1 网格顶层单元 z 跨 `4.0e-4 .. 4.4e-4 m`,
   中心 `4.2e-4 m`;**换一张网格(例如 dt 收敛括号或将来加密网格),
   这个 z 就变了**,而 x/y 是写死的。
2. 规范 §5.1 明确要求 dt 三档"使用完全相同的网格",但没有禁止本项目后续
   引入别的网格;D-V2-10 的立方体模型用的就是 200 µm 单元。
3. 实现上"解析不到包含单元"与"解析到一个很远的单元"在代码里只差一个
   分支。没有规范约束时,最自然的写法恰恰是**静默吸附到最近单元** ——
   那会产出一个看起来完全正常、实际上不在预注册位置的读数。

换句话说:缺这一条时,失效模式是**安静的**,而且产出的数字带着完整的
合规外观。这正是预注册规范存在的理由。

## 提案内容

在 §6.1 的第三条之后增加一条(完整补丁见 `scoring-spec-amendment-A1.patch`):

> - 探针坐标若不落在任何顶层单元内(坐标或网格变更所致),**不得静默取最近
>   单元充作合规读数**:应解析到最近单元、在产物中置 `contains_probe=false`
>   并显式记录该标记与偏移量,该探针本轮的 Fig 15/16 读数记为不可判定;
>   实现不得因此中止运行。

三点设计取舍,都可以推翻,但请连理由一起推翻:

- **不中止运行。** 可观测性功能不该有能力杀掉一次 7.5 h 的生产跑;宁可
  留下带标记的产物,也不要没有产物。
- **仍然解析到最近单元并写出数值**,而不是写 `null`。数值本身对诊断有用
  (能看出偏了多远),但它**不是合规读数**,所以必须带 `contains_probe=false`。
- **判定后果是"不可判定",不是"失败"。** 与规范其余部分的 INVALID 口径
  一致:缺条件时不宣称通过,也不宣称模型错。

## 一条**没有**写进补丁的建议

我原先还想补"element id 的编号基准"(0 基行号 vs 1 基)。**Fable5 复审
2026-08-20 认为不必**,理由是:"取最小"对任何**保序**编号都不变,而
0 基 `fe.cells` 行序与 .inp 单元顺序保序。

我接受这个理由,所以补丁里没有它。保留一句异议备查:该论证对保序编号成立,
但对**重排序**的读入器(例如按 element set 或单元类型分组的读法)不成立。
当前三个预注册探针**每一个**都触发 4 单元并列 → 中心距并列 → element id
最小,两级裁决每次都会走到,所以这条不是死代码。产物 meta 的
`probe_resolution.element_id_convention` 与 `n_tied_on_distance` 已经把实际
使用的约定和并列数留痕,这在可审计性上等价,只是没有规范级约束力。
若将来更换网格读入器,请重新检查这一条。
